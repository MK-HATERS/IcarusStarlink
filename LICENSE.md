## Why a license like this, instead of MIT/GPL?

A standard open-source license lets anyone fork and redistribute a modified copy freely, no
questions asked — including under a different name, with different (or missing) safety
behavior, still pointed at people's real game installs and real save files. Given how much of
this app deliberately gates risky, hard-to-reverse actions (installing into your actual game
folder, editing a real save file, registering an OS-level protocol handler) behind careful
confirmation and backup logic, an unreviewed fork drifting away from those safeguards — while
still looking like "IcarusStarlink" — is a real, specific risk this project would rather avoid.
Keeping modification/redistribution permission-based, while leaving ordinary use and
contributing back both fully open, is meant to strike that balance.
