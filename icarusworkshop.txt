Icarus Workshop
Icarus mod manager for Windows

Merge EXMOD mods, edit them, download updates, share a loadout with friends,
keep UE4SS mods on the same profile, and (in testing) edit player saves.
⚠️ IMPORTANT: Backups & Bug Reporting
Everything should work as intended, but modding always carries some risk.
Manual Save Backups Recommended: While Workshop automatically creates a backup before making any edits to your player data, it is always strongly recommended to make your own manual backup before testing any new mod.
Found a Bug? If you run into issues, please include a diagnostic package with your bug report (Settings → Diagnostics → Export Diagnostics Zip).

What this is
Icarus Workshop is a desktop app for managing Icarus mods.
It focuses on EXMOD data mods: extract them, edit them, merge several into
one IMM_Merged_Mod_P.pak, and install that into the game. It can also
download mods, keep notes/favorites, export a shareable patch for friends or a
server, stage UE4SS (Lua) mods so they install with the same profile, and
edit player saves (still in testing).

It does not replace Unreal Engine for custom Blueprints, and it is not a
Lua scripting IDE. For those, you still author elsewhere and import/stage the
finished package here.

Install
Create a folder for Workshop (example: H:\IMM-Workshop).
    Do not leave it in Downloads. The app writes data next to the exe.
Extract Icarus_Workshop.zip into that folder. Keep
    Icarus_Workshop.exe and the _internal
    folder together. If you still have IMM_Workshop.exe, delete it.
Run Icarus_Workshop.exe.
Open Settings:
Set Icarus Content folder
    (…\Icarus\Icarus\Content)
Set UnrealPak.exe (or use Download UnrealPak)
Click Update data folder (extracts game data Workshop needs for merge/edit)
Download or import mods → add EXMODs to the merge queue → Rebuild & Install.

Updating the app
Checking for updates happens during the launch of the app if an update is found you can click yes to update. If you don't want to restart to check for an update you can just click on check for updates in the settings menu.
OR
Download the latest release zip and overwrite the program files. Your
Extracted_Mods, Profiles, settings, and Cache stay in the install folder if you
only replace the exe / _internal.

Uninstall
Run Uninstall.bat in the Workshop folder. You can keep or
wipe local data. The game install is not removed by the uninstaller.

Merge & install
Library list on this tab uses the same grouping as Library
Ordered merge queue. Later mods win conflicts by default.
Rebuild builds IMM_Merged_Mod_P.pak and installs into Content/Paks/mods
Copy built pack to game (Rebuild ▾ menu) copies the already-built
    Staging pak into the game folder without remelting. Use this if Icarus was open
    during install, or you only need the pack copied back
If the game has the pak locked, Retry does that same copy-only step
Optional auto-backup of the game mods folder before overwrite (keeps last 5)
Optional advanced conflict picker (choose earlier/later per field)
Queue rules for a merged pack: skip mods already inside it; pack can
    replace individuals; new mods can sit beside the pack and merge on top
Prebuilt sidecar .paks and staged UE4SS mods install with the same Rebuild

For mod authors: grouped options in Library / Merge
If you ship several versions of the same mod (bag sizes, extract presets, etc.),
Workshop can show them as one family with each option listed underneath.
The group header is not a mod. Users expand it and add one child to the
merge queue. A family only appears when two or more matching variants are
in Extracted Mods.

Best: declare it in the EXMOD JSON (top-level keys, next to name / fileName).
Put the option at the end of name so the family
title strips cleanly (Take Home Tools → group
Take Home).

"variantGroup": "Take_Home"
"variant": "Tools"
"variantSort": 1

variantGroup: same id on every option (case-insensitive). Example:
    Take_Home or Space_Station_Inventory
variant: label shown under the group (Tools,
    2x, Almost All)
variantSort: optional integer. Lower sorts first (Tools before Almost All).
    If omitted, labels that start with a number (2x, 5x, 10x) sort by that number
Each option still needs its own folder and fileName
Keep these keys if you re-save in the EXMOD editor (Full EXMOD JSON view)

Also works with no extra keys if fileName or
name ends with a multiplier:
MyMod_2x / MyMod_5x /
    MyMod_10x
or display name My Mod 2x
Named options (Tools, Food, Almost All) should use variantGroup. Filename
guessing only understands _2x-style suffixes.

If two options edit the same number field (bag slots, etc.), tell users
to pick one (last in the merge queue wins). Gameplay-tag
Query options combine[/font] in Workshop (Take Home
Tools + Resources keeps both). Options that edit different files can sit
together (Take Home + a bag-size mod is fine).
